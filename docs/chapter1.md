# 1장 「깨진 손목시계」 — 상세 기획 (v0.1)

> 상위 문서: [기획서](기획서.md)
> 예상 플레이 타임: 25~35분
> 테마: **놓쳐버린 시간** — "조금만 더 하고 가면 돼."

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 유실물 | 유리가 깨진 은색 손목시계 (뒷면 각인: *"아빠, 늦지 마 — 서아"*) |
| 기억의 주인 | **강도윤** (42) — 중견 무역회사 '한결물산' 과장 |
| 기억 공간 | 한결물산 7층 사무실. 모든 시계가 **11시 59분**에 멈춰 있고, 창밖은 언제나 밤 |
| 핵심 퍼즐 | 사무실의 '마스터 시계'를 **도윤이 퇴근했어야 했던 시각(17:20)** 에 맞춘다 |
| 공포 포인트 | 그림자 동료들 · 혼자 돌아가는 복사기 · 회의실 슬라이드의 변질 |
| 본편 연결 | 창밖 승강장에 선 **노란 우비**의 첫 등장 / 일기장 첫 [의심] 튜토리얼 |

### 강도윤의 사연
딸 서아(8)의 초등학교 학예회가 있던 금요일. 서아는 연극 「시계 토끼」의 주인공이었다. 도윤은 "보고서만 끝내고 가겠다"고 했지만 부장의 추가 지시로 밤 12시 가까이 회사에 남았다. 서아는 무대에서 끝까지 객석의 빈자리를 바라봤다. 그날 퇴근길, 녹하역 승강장에서 도윤은 서아가 준 손목시계를 떨어뜨렸고 유리가 깨졌다. 그는 시계를 줍지 않았다.

## 2. 맵 구성

```
                 [1-5 부장실]
                      │ (잠김: 부장실 열쇠)
[1-4 탕비실] ── [1-2 사무 공간] ── [1-3 회의실]
                      │
              [1-1 엘리베이터 홀]  ← 진입/퇴장
                      │
              (엘리베이터 = 보관소 귀환)
```

| ID | 맵 이름 | 크기(타일) | 분위기 / 주요 오브젝트 |
|---|---|---|---|
| 1-1 | 엘리베이터 홀 | 17×13 | 깜빡이는 형광등, 층 표시등 '7' 고정, 회사 안내판, **벽시계①**, 화분 |
| 1-2 | 사무 공간 | 25×19 | 칸막이 책상 12개, 그중 8개에 **그림자 동료** 착석. 도윤의 자리(창가), 복사기, **벽시계②**, 창문(승강장이 보임) |
| 1-3 | 회의실 | 15×11 | 긴 테이블, 빔프로젝터, 스크린, 의자 10개(전부 스크린 반대 방향을 봄), **벽시계③** |
| 1-4 | 탕비실 | 11×9 | 커피머신, 냉장고, 정수기, 싱크대에 쌓인 머그컵 |
| 1-5 | 부장실 | 13×11 | 큰 책상, 가죽 의자(등 돌린 채), 블라인드, **마스터 시계**(바늘 없음) |

## 3. 진행 흐름 (공략 순서)

```
보관소에서 손목시계 조사
  → [1-1] 진입, 엘리베이터 고장 확인
  → [1-2] 도윤의 자리 조사 → 학예회 초대장 / 컴퓨터(잠김)
  → 액자 뒷면에서 비밀번호 단서 → 컴퓨터 해제 → 메일 열람
  → [1-4] 탕비실: 커피머신에서 '분침' 획득
  → [1-3] 회의실: 슬라이드 퍼즐 → 지하철 경로(소요 40분) + '시침' 획득
  → [1-2] 복사기 이벤트 → '부장실 열쇠' 획득
  → [1-5] 부장실: 마스터 시계에 바늘 장착 → 17:20 입력
  → 클라이맥스 → [1-1] 도윤에게 시계 반환 → 보관소 귀환
```

탕비실(1-4)과 회의실(1-3)은 순서 자유. 둘 다 끝내야 복사기 이벤트가 발생한다.

## 4. 퍼즐 상세

### 퍼즐 ① 컴퓨터 비밀번호
- **위치**: 1-2 도윤의 책상
- **단서**: 책상 위 엎어진 액자 → 조사 시 뒤집으면 유리가 깨진 가족사진. 한 번 더 조사하면 뒷면 메모:
  > *"우리 공주 여덟 번째 생일 ♥ 4월 12일"*
- **정답**: `0412`
- **오답 시**: 화면에 `다시 생각해보게, 강 과장.` 3회 오답마다 그림자 동료 1명이 일어서서 하연 쪽을 본다(연출만, 위험 없음).

### 퍼즐 ② 회의실 슬라이드
- **위치**: 1-3 빔프로젝터
- 프로젝터를 켜면 슬라이드 6장이 순서 없이 나온다. 각 장은 **가족 사진과 업무 보고서가 반쯤 섞인 이미지**.
- 리모컨으로 슬라이드 순서를 바꿔 '퇴근길'을 완성해야 한다.

| 정답 순서 | 슬라이드 내용 | 표시 텍스트 |
|---|---|---|
| 1 | 회사 정문 | 한결물산 → 한결역 도보 5분 |
| 2 | 한결역 승강장 | 2호선 탑승 |
| 3 | 환승 통로 | 녹하역 환승 10분 |
| 4 | 녹하선 열차 내부 | 녹하선 3정거장 15분 |
| 5 | 학교 앞 횡단보도 | 서아초등학교 도보 10분 |
| 6 | 강당 무대 | **총 소요시간 40분** |

- **완성 시**: 스크린 전체에 무대 위 서아 사진이 뜬다. 객석 맨 앞줄 한 자리만 비어 있다. 프로젝터 렌즈 덮개 안쪽에서 **'시침'** 획득.
- **틀린 순서로 확정 시**: 슬라이드가 전부 엑셀 표로 바뀌며 `REVISION REQUIRED` 경고. 리셋.

### 퍼즐 ③ 탕비실 커피머신
- **위치**: 1-4
- 커피머신 화면: `메뉴를 선택하세요` → 선택지 [아메리카노 / 믹스커피 / 코코아]
- **단서**: 냉장고 문에 붙은 서아의 그림 — 아빠와 서아가 각자 컵을 들고 있음. 서아 컵에 "코코아", 아빠 컵에 "아빠는 맨날 쓴 거".
- **정답**: 코코아 → 컵 바닥에 가라앉은 **'분침'** 획득.
- **오답**: 아메리카노/믹스커피를 고르면 커피가 끝없이 넘쳐흐르고 바닥이 검게 물든다(1-4 재진입 시 원상복구). 정신력 -1.

### 퍼즐 ④ 마스터 시계 (최종)
- **위치**: 1-5 부장실
- 시침·분침을 장착하면 시각 입력 UI가 열린다(시/분 다이얼).
- **필요 정보**
  - 학예회 초대장: *"연극 「시계 토끼」 — 오후 6시 시작"*
  - 회의실 슬라이드: 총 소요 40분
  - 컴퓨터 메일(아내): *"막 시작하면 서아 많이 긴장해. 꼭 시작 전에 와줘."*
- **정답**: `17:20`
- **허용 오답**: `17:00~17:19` 입력 시 "…너무 이른 건 아닐까. 아직 할 일이 남았는데." 라는 도윤의 목소리 후 리셋 (페널티 없음)
- **오답(17:21 이후)**: 아래 '야근 이벤트' 발생.

#### 야근 이벤트 (오답 페널티)
1. 모든 형광등이 꺼지고 마스터 시계가 다시 11:59로 돌아간다.
2. 1-2로 강제 이동. 그림자 동료 8명이 전원 일어서서 키보드를 두드리는 소리만 난다.
3. 하연이 지나가는 책상마다 모니터에 `야근 확정` 문구.
4. 1-5에 다시 들어가면 이벤트 종료. 정신력 -2.

## 5. 주요 이벤트 & 대사 스크립트

> 표기: **하연**(주인공) / **도윤**(목소리 또는 실루엣) / *(지문)*

### E1-01. 진입 (1-1)
*(엘리베이터 문이 열린다. 형광등이 두 번 깜빡인다.)*
**하연**: …회사? 여긴 역이 아닌데.
*(벽시계를 조사하면)*
**하연**: 11시 59분. 초침이 움직이질 않아.
*(엘리베이터 버튼을 조사하면)*
**하연**: 눌러지지 않아. …무언가를 끝내야 나갈 수 있는 걸까.

### E1-02. 도윤의 자리 (1-2)
*(책상 위 명패: 「과장 강도윤」)*
*(모니터 옆에 접힌 초대장)*
> 서아초등학교 2학년 1반 학예회
> 연극 「시계 토끼」 — 주인공: 강서아
> 일시: 금요일 오후 6시 / 장소: 본관 강당
> *(삐뚤빼뚤한 글씨로)* 아빠 맨 앞에 앉아!

**하연**: …금요일 오후 6시.

### E1-03. 컴퓨터 메일함 (퍼즐① 해제 후)
| 보낸 사람 | 시각 | 제목 / 본문 |
|---|---|---|
| 박 부장 | 16:52 | 「분기 보고서 금일 중」 — *강 과장, 오늘 안에 올리고 가. 월요일 아침 임원 보고야.* |
| 아내 | 17:05 | 「오늘 잊지 않았지?」 — *막 시작하면 서아 많이 긴장해. 꼭 시작 전에 와줘.* |
| 아내 | 18:14 | 「어디야」 — *(본문 없음)* |
| 아내 | 19:30 | 「…」 — *서아가 마지막 인사 할 때까지 객석만 봤어.* |
| 발신자 없음 | 23:59 | 「(제목 없음)」 — *지금이라도 가면 늦지 않을까요?* |

> 마지막 메일은 하연에게 보내는 것처럼 읽히도록. 보관소 직원의 말투와 같다(숨겨진 엔딩 D 복선).

### E1-04. 창문 (1-2) — 노란 우비 첫 등장
*(사무실 창문을 조사하면, 바깥 풍경이 도시가 아니라 지하철 승강장이다.)*
**하연**: 창밖이… 승강장?
*(승강장 끝에 노란 우비를 입은 작은 아이가 서 있다. 하연이 바라보자 아이가 고개를 든다.)*
*(화면 암전 1초)*
*(다시 보면 아무도 없다.)*
**하연**: ……하준?

- 이벤트 1회성. 이후 창문 조사 시 "비어 있는 승강장이다."
- **일기 자동 기록 발생** (아래 7장 참고)

### E1-05. 복사기 (1-2) — 탕비실·회의실 클리어 후
*(사무실 구석 복사기가 혼자 작동하기 시작한다. 덜컥, 덜컥.)*
*(조사하면 출력된 종이가 계속 쌓인다.)*
> 퇴근하지 마
> 퇴근하지 마
> 퇴근하지 마
> 아빠 언제 와
> 퇴근하지 마

*(마지막 장 사이에 열쇠가 끼어 있다.)*
**하연**: 부장실 열쇠…. 이 사람, 계속 붙잡혀 있었구나.
*(하연이 뒤돌면 가장 가까운 그림자 동료 하나가 일어서 있다. 다가가면 다시 앉는다.)*

### E1-06. 부장실 (1-5)
*(등 돌린 가죽 의자. 조사하면)*
**???**: 강 과장, 가족은 이해해줄 거야. 회사는 아니지.
*(의자가 천천히 돈다 — 비어 있다.)*

### E1-07. 클라이맥스 (정답 17:20 입력 후)
*(마스터 시계의 바늘이 17:20을 가리키는 순간, 모든 벽시계가 동시에 째깍이기 시작한다.)*
*(사무실 형광등이 하나씩 꺼지고, 그림자 동료들이 하나씩 사라진다.)*
*(1-1 엘리베이터 홀. 엘리베이터 앞에 양복 차림의 남자 실루엣.)*

**도윤**: …몇 시예요, 지금.
**하연**: 다섯 시 이십 분이요.
**도윤**: 그럼… 아직 늦지 않았네요.
*(하연이 손목시계를 건넨다. 도윤이 깨진 유리를 손끝으로 쓸어본다.)*
**도윤**: 이거, 딸이 준 거예요. 늦지 말라고.
**도윤**: 그날 승강장에 떨어뜨렸는데… 줍지 않았어요. 주우면, 내가 늦었다는 걸 인정하는 것 같아서.
**도윤**: 학생도 뭔가 두고 왔죠? 이 역에.
**하연**: ……
**도윤**: 너무 오래 두면, 주우러 가는 게 더 무서워져요.
*(엘리베이터 문이 열린다. 도윤이 탄다. 문이 닫히기 직전)*
**도윤**: 고마워요. 이번엔, 맨 앞자리에 앉을게요.

*(엘리베이터 층 표시등이 '7'에서 'B1'로 바뀐다.)*

### E1-08. 보관소 귀환
*(보관소. 선반에서 손목시계가 있던 자리에 꼬리표만 남아 있다: 「반환 완료」)*
**보관소 직원**: 돌려주셨군요. 주인이 기뻐했겠어요.
**보관소 직원**: …창밖에서 뭔가 보셨나요?
- 선택지
  - **[봤어요]** → 직원: "그렇군요. 그 아이도 꽤 오래 기다렸으니까요." *(플래그: `ch1_told_truth`)*
  - **[아무것도]** → 직원: "…그런가요." *(정신력 -1, 플래그 없음)*

## 6. 쪽지 / 수집 요소 전문

수집 쪽지는 1장에 5개. 전부 모으면 보관소에서 직원과의 추가 대화 해금(엔딩 D 조건 일부).

| No | 위치 | 내용 |
|---|---|---|
| 1-A | 1-1 화분 아래 | *"7층은 엘리베이터가 자주 멈춥니다. 비상시 내선 0412."* — 관리실 |
| 1-B | 1-2 동료 책상 서랍 | *"강 과장님 오늘도 막차 타시겠네. 부장님 또 금요일 저녁에 일 던지심 ㅋ"* (메신저 출력물) |
| 1-C | 1-3 의자 밑 | 서아의 연극 대본 한 페이지: *"시계 토끼야, 왜 그렇게 서둘러? / 늦으면 소중한 사람이 기다리다 지쳐버리거든!"* |
| 1-D | 1-4 싱크대 머그컵 안 | *"아빠 커피 너무 써. 서아가 코코아 사줄게."* (어린이 글씨) |
| 1-E | 1-5 블라인드 사이 | 녹하역 분실물 신고서 사본. 분실물: 손목시계 / 신고자: 없음 / 접수 직원 서명란: **(긁혀서 지워짐)** |

> 1-E의 '지워진 서명'은 보관소 직원의 명찰과 같은 필체 — 엔딩 D 복선.

## 7. 일기장 연동 (1장 분량)

1장에서 **[의심] 시스템 튜토리얼**을 진행한다. 거짓 기억은 1개만 배치.

| 트리거 | 일기 문장 | 진위 | 어긋남 단서 |
|---|---|---|---|
| E1-01 진입 | 오늘 처음 와보는 곳이다. 회사 같은 곳. | 참 | — |
| E1-02 초대장 | 학예회는 금요일 6시. 아빠가 오지 않은 아이. | 참 | — |
| E1-04 창문 | 창밖 승강장에 **아무도 없었다.** 피곤해서 잘못 본 것 같다. | **거짓** | 플레이어는 노란 우비를 직접 봤다. 일기를 열면 '아무도' 부분 글씨가 살짝 번져 있다. |
| E1-07 반환 | 그 사람은 시계를 받고 웃었다. 나는 아무것도 두고 오지 않았다. | **부분 거짓** (2장 이후 판정) | 앞 문장은 참, 뒤 문장은 거짓. 1장에서는 [의심] 불가, 4장에서 재등장. |

#### 튜토리얼 흐름
1. E1-04 직후 일기장 아이콘이 깜빡임 → 열면 해당 문장에 밑줄.
2. 시스템 안내: *"기억과 다른 문장이 있다면 [의심]할 수 있습니다."*
3. [의심] 선택 시 문장 옆에 붉은 물음표 표시. 정신력 변화 없음.
4. [의심]하지 않고 닫으면, 보관소 귀환 시 해당 문장이 굵은 글씨로 덧써져 있다(정신력 -1).

## 8. 그림자 동료 행동 규칙

1장의 '공포 요소'이지만 **직접적인 위협은 없음.** 추격은 2장부터.

| 상황 | 행동 |
|---|---|
| 기본 | 책상에 앉아 타이핑 소리. 하연이 2타일 이내로 접근하면 타이핑이 멈춘다. |
| 하연이 등을 보이고 3초 이상 | 가장 가까운 1명이 일어서 있다. 뒤돌면 앉아 있음. |
| 컴퓨터 비밀번호 3회 오답 | 1명이 일어서서 하연 쪽을 계속 바라봄 (해당 맵 재진입 시 리셋) |
| 야근 이벤트 | 전원 기립, 동시 타이핑 |
| 퍼즐 ④ 정답 후 | 순차 소멸. 마지막 1명은 사라지기 전에 고개를 숙여 인사 |

## 9. 연출 & 사운드 큐

> 오디오 원칙은 [기획서 8-1](기획서.md#8-1-오디오-원칙)을 따른다. **1장 탐색 중에는 BGM 없음.**

### 9-1. 맵별 환경음 / 주변음

| 맵 | ① 베이스 환경음 (루프) | ② 주변음 (랜덤) |
|---|---|---|
| 1-1 엘리베이터 홀 | 형광등 웅웅거림 + 깜빡일 때 '틱' 소리 | 엘리베이터 케이블 삐걱임, 문이 반쯤 열렸다 닫히는 소리, 멀리서 '띵' 도착음 |
| 1-2 사무 공간 | 형광등, 컴퓨터 팬 소음, 그림자 동료 타이핑 | 의자 바퀴 구르는 소리, 마우스 클릭, 전화벨 한 번 울리다 끊김, 누군가 한숨 쉬는 소리 |
| 1-3 회의실 | 빔프로젝터 팬 소음, 에어컨 | 의자 하나가 끌리는 소리, 낮게 웅얼거리는 회의 목소리(알아들을 수 없음) |
| 1-4 탕비실 | 냉장고 컴프레서, 정수기 물방울 | 커피머신 혼자 '삐' 소리, 머그컵 부딪히는 소리, 싱크대 물 한 방울 |
| 1-5 부장실 | 거의 무음 + 낮은 에어컨 | 가죽 의자 삐걱, 블라인드 흔들림, 헛기침 |
| 전 구역 공통 | — | 아주 드물게(1장 전체 2~3회) 창 쪽에서 **열차 지나가는 진동음** |

- 그림자 동료 근처(2타일)에 가면 타이핑 소리가 멈춘다 → **그 순간의 정적**이 1장 기본 공포 장치.
- 정신력 7 이하: 주변음에 **아이 허밍**(「시계 토끼」 멜로디 몇 음)이 섞이기 시작.

### 9-2. 이벤트별 사운드 & 연출

| 구간 | 사운드 | BGM | 연출 |
|---|---|---|---|
| 창문 이벤트 (E1-04) | 열차 진입음 → 완전 무음 2초 → 형광등 복귀 | 없음 | 우비만 노란색, 나머지 채도 0 |
| 복사기 (E1-05) | 기계음 반복, 종이 쌓이는 소리, 마지막 장에서 뚝 끊김 | 없음 | 화면 미세 흔들림 |
| 부장실 의자 (E1-06) | 목소리 직후 의자 회전음, 이후 무음 | 없음 | 의자가 돌면 비어 있음 |
| **야근 이벤트** | 수십 개의 키보드 소리 겹침 | **있음** — 불협화음 현악 드론, 점점 커짐 | 조명 OFF, 모니터 빛만 |
| **클라이맥스 (E1-07)** | 시계 째깍임 겹침 → 하나로 수렴 | **있음** — 째깍임 박자 위로 낮은 피아노 | 형광등 순차 소등 |
| **반환 장면** | 엘리베이터 도착음 | **있음** — 오르골 「시계 토끼」 짧은 멜로디 | 엘리베이터 문틈에서 따뜻한 빛 |
| 보관소 귀환 (E1-08) | 보관소 환경음 복귀 | 없음 (오르골 페이드아웃) | — |

### 9-3. 필요 음원 목록

- **BGM (3곡)**: 야근(불협화음 드론), 클라이맥스(시계+피아노), 시계 토끼(오르골)
- **환경음 루프 (6종)**: 형광등, 사무실 팬/타이핑, 프로젝터, 냉장고/정수기, 에어컨, 엘리베이터 홀

- **이벤트음**: 열차 진입, 복사기, 의자 회전, 키보드 다중, 시계 째깍임
