# 한국인 셀카 데이터 수집 · 재학습 가이드

목표: 연구용 데이터(Deep Armocromia, 서양 연예인 사진)에 의존하는 현재 모델을 **한국인 셀카 + 전문가 진단 결과**로 다시 학습한다.
상업적 이용 문제(연구용 한정 라이선스)도 이 과정으로 해결한다.

## 1. 무엇을 모으나 — 사진은 모으지 않는다

| 항목 | 내용 | 비고 |
|---|---|---|
| 색 수치 30개 | 피부·머리카락·눈 영역의 L\*, a\*, b\*, ITA, 채도의 평균·표준편차 | 기기 안에서 계산. 모델 입력과 동일 |
| 전문가 진단 | 계절(필수), 12톤(선택), 진단서 원문 이름, 확신도 | 16타입 등 다른 체계는 원문 이름으로 보관 |
| 촬영 조건 | 염색 여부, 메이크업, 조명 | 학습 시 염색 머리는 머리 수치를 제외 |
| 측정 품질 | 화이트밸런스 보정값, 품질 점수, 경고 코드 | 저품질 데이터 필터링용 |
| AI 결과 | 당시 모델의 상위 3개 톤 | 모델-전문가 일치율 추적 |
| 동의 기록 | 동의서 버전, 동의 시각 | |

**얼굴 사진 원본, 이름, 연락처는 수집하지 않는다.** 스키마: `web/src/lib/contribute/schema.ts`

## 2. 수집 경로

### A. 컨설턴트 모드 (`#consultant`) — 핵심 경로
1. 컨설턴트가 매장 코드를 입력한다.
2. 고객 사진을 촬영·선택하면 기기에서 색을 측정한다 (품질이 나쁘면 재촬영 안내).
3. **AI 결과를 보지 않은 상태로** 드레이핑 진단 결과를 입력한다 (선입견 방지).
4. 고객 동의 체크 후 제출하면 AI 결과가 공개된다 (비교용).

### B. 일반 사용자 피드백
진단 결과 화면의 "전문가에게 진단받은 적 있나요?" 카드에서 과거 진단 결과를 입력한다. 라벨 품질은 A보다 낮다(진단 시점과 촬영 시점이 다름). 학습 시 가중치를 조정할 수 있다.

### 저장 위치
| 환경 | 저장소 | 내보내기 |
|---|---|---|
| 웹앱 (Next.js) | `DATABASE_URL` 있으면 Postgres, 없으면 `.data/*.jsonl` | `GET /api/contributions/export` + `Authorization: Bearer $CONTRIBUTIONS_ADMIN_TOKEN` |
| 미리보기 페이지 | claude.ai 아티팩트 DB (`contributions/<사용자>/entries/<id>`) | 소유자가 `#admin` 화면에서 "JSONL로 내보내기" |

접근 권한: 각 참여자는 자기 기여만 읽고 쓰기·삭제, 전체 열람은 소유자·편집자만. 미리보기에서 제출하려면 링크 공유 시 **참여자(Contributor)** 이상 권한이 필요하다.

### 철회
기여한 기기의 "내가 보낸 데이터"에서 삭제. 웹앱은 제출 시 발급한 삭제 토큰으로, 미리보기는 본인 계정으로 삭제한다. 다음 재학습부터 제외된다.

## 3. 컨설턴트 제휴 프로토콜

**촬영 기준** (데이터 품질의 대부분이 여기서 결정됨)
- 낮 시간 창가 자연광, 직사광선 피하기. 매장 조명이 강하면 끄기
- 정면, 얼굴이 화면의 1/3 이상, 머리카락이 보이게
- 맨얼굴 또는 선크림·기초까지. 컬러렌즈 X
- 가능하면 같은 자리·같은 기기로 촬영 (매장별 일관성)

**진단 기준**
- 드레이핑 진단을 모두 마친 뒤 최종 결과 입력
- 두 톤 사이에서 갈렸으면 "애매했어요" 선택 (학습 가중치 0.5)
- 가능하면 일부 고객(예: 10%)은 **두 번째 컨설턴트가 독립적으로 진단** → 전문가 간 일치율 측정 (모델 정확도의 현실적 상한을 알 수 있음)
- 염색 여부를 정확히 기록 (머리색이 가장 중요한 단서라 왜곡이 큼)

**동의**
- 고객에게 화면의 "AI 학습용 데이터 제공 안내"를 보여주고 구두·체크 동의
- 만 14세 미만 고객은 제출하지 않음

## 4. 몇 건이 필요한가

Deep Armocromia로 측정한 학습 데이터 양별 성능(같은 테스트셋 912장, 5회 평균):

| 학습 데이터 | 4계절 1순위 | 12톤 상위 3개 |
|---|---|---|
| 300건 | 49% | 57% |
| 600건 | 52% | 60% |
| 1,000건 | 53% | 62% |
| 2,000건 | 55% | 64% |
| 4,008건 | 56% | 65% |

연예인 사진(조명·메이크업 제각각)의 결과라, 촬영 기준을 지킨 컨설턴트 데이터는 같은 양으로 더 높은 정확도가 나올 가능성이 있다. 이것이 이 프로젝트의 핵심 가설이다.

| 단계 | 목표 | 할 일 |
|---|---|---|
| 1단계 | 컨설턴트 데이터 **300건** | 현재 모델의 한국인 정확도 측정 (기준선), 전문가 간 일치율 측정 |
| 2단계 | **1,000건** (톤별 50건 이상) | 기존 데이터 + 한국인 데이터 혼합 학습, 한국인 테스트셋에서 개선 확인 |
| 3단계 | **2,000건 이상** (톤별 100건 이상) | 한국인 데이터만으로 학습 (`--no-base`) → 상업 출시 가능한 모델 |

매장 1곳에서 하루 5명이면 2,000건까지 매장 5곳 기준 약 4개월.

## 5. 재학습 절차

```bash
# 1) 내보내기 (웹앱)
curl -H "Authorization: Bearer $CONTRIBUTIONS_ADMIN_TOKEN" https://<host>/api/contributions/export > contributions.jsonl
# 2) 학습용 CSV로 변환 (매장 단위로 train/test 분리 → 같은 매장 고객이 양쪽에 섞이지 않음)
python3 ml/export_contributions.py korean.csv contributions.jsonl
# 3) 혼합 학습 + 비교 (한국인 테스트셋에서 기존 모델 vs 새 모델)
python3 ml/train.py features_30_per_region.csv --extra korean.csv --export web/src/lib/analysis/model.json
# 3') 충분히 모이면 한국인 데이터만으로
python3 ml/train.py --no-base --extra korean.csv --export web/src/lib/analysis/model.json
```

옵션: `--extra-weight` (한국인 데이터 가중치, 기본 3), `--unsure-weight` (애매한 라벨, 기본 0.5),
`--dyed-hair impute|keep|drop` (염색 머리 처리, 기본 impute), `--min-quality` (품질 점수 하한, 기본 0.4).
`model.json`의 `researchOnlyData`가 `false`인 모델만 상업 서비스에 사용한다.

파이프라인 점검: `python3 ml/test_pipeline.py features_30_per_region.csv` (가짜 기여 데이터로 전체 흐름 검사)
