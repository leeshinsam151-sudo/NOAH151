# 셀카 기반 퍼스널 컬러 진단 앱 — 설계 문서

## 1. 목표

- 사용자가 셀카를 올리면 **퍼스널 컬러(4계절 → 12톤)** 를 진단한다.
- 결과로 **베스트/워스트 컬러 팔레트**, 메이크업·헤어·의상·액세서리(골드/실버) 추천을 준다.
- 핵심 원칙: **정확도보다 "재현성"과 "솔직함"**. 조명이 나쁘면 진단하지 않고 재촬영을 요청하며, 결과에 신뢰도를 함께 보여준다.

## 2. 가장 큰 기술적 난관: 사진 속 색은 진짜 피부색이 아니다

| 왜곡 요인 | 대응 |
|---|---|
| 조명 색온도(형광등·백열등·노을) | 촬영 가이드(창가 자연광), 화이트밸런스 보정 |
| 폰 카메라 자동 보정·뷰티 필터 | 기본 카메라 사용 안내, 앱 내 촬영 시 필터 없는 원본 사용 |
| 메이크업 | "노메이크업 또는 베이스만" 안내 |
| 노출 과다/부족, 그림자 | 품질 검사 후 재촬영 요청 |

**화이트밸런스 보정 방법 (우선순위 순)**
1. **기준 카드 방식(선택)**: 흰 종이(A4)를 얼굴 옆에 들고 촬영 → 종이 영역을 중립 회색으로 맞춤. 가장 정확.
2. **눈 흰자·치아 기반 추정**: 랜드마크로 공막(눈 흰자) 영역을 잡아 중립색 기준으로 사용.
3. **Gray-world / 배경 기반 추정**: 위 둘이 불가능할 때 fallback, 신뢰도 하향.

## 3. 분석 파이프라인

```
사진 입력
  └─▶ ① 얼굴 검출·랜드마크 (MediaPipe Face Landmarker, 478점)
        └─▶ ② 품질 검사 (얼굴 크기·정면 각도·흐림·노출·색온도 편차)
              ├─ 불합격 → 재촬영 안내 (이유 구체적으로)
              └─▶ ③ 영역 분할
                    - 피부: 양 볼 + 이마 + 턱 (눈썹·수염·그림자·하이라이트 제외)
                    - 홍채, 눈 흰자, 입술, 머리카락(헤어 세그멘테이션)
                    └─▶ ④ 화이트밸런스 보정
                          └─▶ ⑤ 색공간 변환 sRGB → CIELAB / LCh
                                └─▶ ⑥ 특징 추출
                                      └─▶ ⑦ 분류 (언더톤·명도·채도·대비 → 계절·12톤)
                                            └─▶ ⑧ 결과 + 신뢰도
```

### ⑥ 특징 (Feature)

각 영역에서 이상치(하이라이트/그림자)를 제거한 뒤 **중앙값** 사용.

| 특징 | 계산 | 의미 |
|---|---|---|
| 피부 L* | Lab 명도 | 밝기 |
| 피부 a*, b* | Lab 색좌표 | 붉은기 / 노란기 |
| 피부 hue angle h° | atan2(b*, a*) | 언더톤 핵심 지표 (높을수록 노란기=웜) |
| 피부 Chroma C* | √(a*² + b*²) | 피부 채도 |
| ITA° | atan((L* − 50) / b*) × 180/π | 피부 밝기 등급 |
| 머리·눈동자 L* | Lab 명도 | 모발/눈 색 깊이 |
| 대비(Contrast) | 피부 L* − 머리 L*, 피부 L* − 홍채 L* | 고대비=윈터/브라이트 |
| 입술 h°, C* | | 보조 언더톤 지표 |

### ⑦ 분류 — 4축 점수 모델

```
warmth   (웜 ↔ 쿨)      : 피부 h°, b*, 입술 h°
value    (라이트 ↔ 딥)   : 피부 L*, 머리 L*, 홍채 L*
chroma   (클리어 ↔ 뮤트) : 피부 C*, 홍채 C*, 대비
contrast (고대비 ↔ 저대비): 피부-머리 L* 차이, 피부-홍채 L* 차이
```

각 축은 기준 데이터의 평균·표준편차로 **z-score 정규화** 후 가중합. 가중치와 기준값은 라벨 데이터로 보정한다.

**4계절 매핑**

| | 클리어/밝음 | 뮤트/부드러움 |
|---|---|---|
| **웜 + 라이트** | 봄(Spring) | — |
| **쿨 + 라이트** | — | 여름(Summer) |
| **웜 + 딥** | — | 가을(Autumn) |
| **쿨 + 딥** | 겨울(Winter) | — |

**12톤 세분화 (주 축 → 보조 축)**

| 계절 | 세부 톤 |
|---|---|
| 봄 | 라이트 스프링 · 트루(웜) 스프링 · 브라이트 스프링 |
| 여름 | 라이트 서머 · 트루(쿨) 서머 · 소프트 서머 |
| 가을 | 소프트 오텀 · 트루(웜) 오텀 · 딥 오텀 |
| 겨울 | 딥 윈터 · 트루(쿨) 윈터 · 브라이트 윈터 |

12톤은 각 톤의 "중심점"을 4축 공간에 두고, 사용자 점수와의 거리로 softmax 확률을 계산 → **1순위 + 2순위 톤과 확률**을 함께 표시.

**신뢰도** = (품질 점수) × (1순위 확률 − 2순위 확률 margin) × (화이트밸런스 방식 계수). 일정 값 미만이면 "애매함 — 기준 카드로 재촬영 권장".

### 단계별 모델 고도화

| 단계 | 방식 | 비고 |
|---|---|---|
| v0 (MVP) | 위 규칙 기반 점수 | 데이터 없이 시작 가능, 설명 가능 |
| v1 | 특징 벡터 → Gradient Boosting(LightGBM 등) | 전문가 라벨 수백~수천 건 필요 |
| v2 | 얼굴 크롭 이미지 CNN/ViT 파인튜닝 + 특징 결합 | 데이터 수천 건 이상, 서버 추론 |

## 4. 시스템 아키텍처

**권장: 온디바이스 분석 + 서버는 숫자만 받는 하이브리드**

```
[클라이언트]                                   [서버]
 카메라/갤러리                                  API (FastAPI)
  → MediaPipe (얼굴·세그멘테이션)                 ├─ 분류 모델 (v0 규칙 / v1 ML)
  → 품질 검사, WB 보정, 특징 추출   ──특징 벡터──▶ ├─ 팔레트·추천 콘텐츠
  ← 결과 렌더링, 가상 드레이핑      ◀──결과───── ├─ PostgreSQL (결과·이력)
                                                 └─ (동의 시) 학습용 이미지 → 객체 스토리지
```

- 사진 원본은 기본적으로 **서버로 전송하지 않음** → 개인정보 부담·서버 비용·업로드 지연 감소.
- 학습 데이터 기여에 동의한 경우에만 이미지 업로드.
- 서버 모델을 바꿔도 앱 업데이트 없이 반영 가능 (`model_version` 기록).

| DB | PostgreSQL | |

## 5. 사용자 흐름 (화면)

1. **온보딩** — 퍼스널 컬러 소개, 개인정보 처리 동의
2. **촬영 가이드** — 자연광·정면·노메이크업·머리 넘기기·필터 끄기 (일러스트 체크리스트)
3. **촬영/업로드** — 앱 내 촬영 시 얼굴 가이드 프레임 + 실시간 밝기/각도 피드백
4. **품질 검사** — 실패 시 "얼굴이 너무 어두워요", "조명이 노랗게 치우쳐 있어요" 등 구체 안내
5. **(선택) 기준 카드 촬영** — 흰 종이 들고 한 장 더 → 정확도 향상
6. **분석 중** — 2~3초 애니메이션
7. **결과**
   - 메인: "당신은 **라이트 스프링** (신뢰도 82%) · 2순위 브라이트 스프링"
   - 4축 차트 (웜/쿨, 라이트/딥, 클리어/뮤트, 대비)
   - 측정된 피부·머리·눈 색 칩
   - 베스트 컬러 팔레트 / 워스트 컬러
8. **가상 드레이핑** — 얼굴 아래 컬러 천을 합성해 베스트 vs 워스트를 직접 비교 (스와이프)
9. **추천** — 립·블러셔·아이섀도·염색·옷·액세서리(골드/실버)
10. **결과 카드 공유** — 인스타 스토리 비율 이미지 (바이럴 핵심)
11. **이력** — 여러 번 진단 결과 비교, 삭제

## 6. 데이터 모델

```sql
users (
  id uuid pk, created_at, birth_year, consent_training bool
)

analyses (
  id uuid pk, user_id fk null,           -- 비회원 허용
  created_at, model_version text,
  wb_method text,                         -- 'card' | 'sclera' | 'grayworld'
  quality_score real,
  features jsonb,                         -- 피부/머리/눈/입술 Lab 값 등
  axis_scores jsonb,                      -- {warmth, value, chroma, contrast}
  season text, tone text,                 -- 'spring', 'light_spring'
  tone_probs jsonb,                       -- 12톤 확률
  confidence real,
  user_feedback text null                 -- '맞아요' / '전문가 진단은 OO였어요'
)

palettes (
  tone text pk, best jsonb, worst jsonb, description text
)

recommendations (
  id, tone text, category text,           -- lip, blush, hair, cloth, accessory
  name, hex, product_url null, priority
)

training_images (                         -- 동의자만
  id, analysis_id fk, storage_key, expert_label text null, created_at
)
```

## 8. 정확도 확보 전략

- **라벨 데이터**: 오프라인 퍼스널 컬러 컨설턴트와 제휴 → 드레이핑 진단 받은 고객의 동의 사진 + 진단 결과 수집. 앱 내 "전문가 진단 결과 입력" 피드백도 활용.
- **평가 지표**: 4계절 정확도, 12톤 Top-1 / Top-2 정확도, 웜/쿨 이진 정확도.
- **재현성 테스트**: 같은 사람을 다른 조명·기기로 여러 번 촬영 → 결과 일치율 측정 (정확도만큼 중요).
- **공정성**: 피부톤 밝기(ITA 구간)별 정확도를 따로 측정해 특정 피부톤에서 성능이 떨어지지 않는지 확인.
- 출시 초기에는 "웜/쿨 + 4계절"을 메인으로, 12톤은 "참고" 표기 권장.

## 9. 개인정보·법적 고려 (한국 기준)

- 얼굴 사진은 개인정보 → 수집·이용 목적, 보관 기간을 명시한 동의 필요.
- **원본 미저장이 기본값**, 학습 활용은 **별도 선택 동의**.
- 만 14세 미만은 법정대리인 동의 필요 → 가입 시 연령 확인.
- 결과·이미지 삭제 기능, 회원 탈퇴 시 즉시 파기.
- 결과는 "참고용 자가 진단"이라는 고지 (전문가 진단 대체 아님).
- 서비스 출시 전 개인정보 처리방침 법률 검토 권장.

## 10. 수익 모델 (선택)

- 화장품·의류 제휴 커머스 (톤 매칭 상품 추천, 어필리에이트)

## 13. 라벨 데이터 조사 결과

| 데이터 | 규모 | 라벨 | 이용 조건 | 판단 |
|---|---|---|---|---|
| [Deep Armocromia](https://github.com/lorenzo-stacchio/Deep-Armocromia) (ECCV 2024 W) | 4,920장 (train 4,008 / test 912) | 4계절 + 12 하위 톤, 전문가 라벨 | 연구 목적 한정, 신청서 제출 후 비밀번호. 일부 CelebA(비상업) | **MVP 학습에 사용** |
| [armocromia-classical-ml](https://github.com/nypoclary/armocromia-classical-ml) | 위 데이터의 LAB 특징 30개 CSV | 동일 | MIT (원본 이미지 미포함) | **모델 학습에 직접 사용** |
| Roboflow "Capstonea" | 약 230장 | 4계절 | 미확인 | 규모 작음, 보류 |
| AI Hub 한국인 얼굴 데이터 | 대규모 | 퍼스널 컬러 라벨 없음 | 국내 신청 | 라벨 직접 붙여야 함 → 상용화 단계 후보 |

**현재 모델 (v1)**: 영역별 LAB 특징 30개 → 로지스틱 회귀. 공식 테스트셋 기준 계절 Top-1 56.3%, Top-2 83.3%, 12톤 Top-1 32.8%, Top-3 64.6%.
논문의 딥러닝 기준선(FaRL, 55.4%)과 비슷한 수준이며, 12톤 단일 정답은 어렵기 때문에 UI에서는 1~3순위와 확률을 함께 보여준다.

**상용화 전 필수 작업**
1. Deep Armocromia는 연구용 → 상업적 이용 허락을 받거나 자체 데이터로 대체.
2. 자체 데이터: 퍼스널 컬러 컨설턴트 제휴로 한국인 진단 사진 + 결과 수집 (동의 기반). 앱 내 "전문가 진단 결과 입력" 피드백 활용.
3. 학습 데이터는 연예인 사진(전문 조명) → 실제 셀카와 분포가 다름. 자체 셀카 데이터로 재보정 필요.
