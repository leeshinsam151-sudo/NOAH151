## 1. 개요

| 항목 | 내용 |
|---|---|
| 유실물 | 녹슨 열쇠 꾸러미. 역무원 명찰 고리가 달려 있고, 열쇠 하나에만 「보관소」 꼬리표 |
| 기억의 주인 | **오정호** (당시 54세) — 녹하역 야간 역무원. 2016년 폐역과 함께 퇴직 |
| 기억 공간 | **2016년 11월 4일의 녹하역**과 **현재의 폐역**. 같은 공간의 두 시간대를 오가며 진행 |
| 핵심 퍼즐 | 과거/현재 역의 차이를 비교해 잠긴 **관제실(CCTV실)** 에 진입, 그날의 영상을 순서대로 재생 |
| 공포 포인트 | 시간대가 바뀔 때마다 사라지거나 생겨나는 사람들 · 안내방송이 하연의 이름을 부름 · 영상 속 '하연' |
| 본편 반전 | **CCTV 속 하준의 손을 잡고 승강장에 들어온 사람은 일곱 살의 하연 자신.** 18:52, 하연은 혼자 나간다 |

### 오정호의 사연
그날 밤 19시 30분, 정호는 승강장 벤치에 혼자 앉은 노란 우비의 아이를 발견했다. 아이는 "누나가 여기서 기다리랬어"라며 자리를 뜨지 않으려 했고, 정호는 자기 모자를 씌워 주며 달랬다. 결국 아이를 유실물 보관소로 데려가 난로 앞에 앉히고, 21시 15분 안내방송으로 보호자를 찾았다.
21시 20분, 한 여성이 "아이 보호자"라며 찾아왔다. 정호는 순찰 호출에 쫓겨 신분을 제대로 확인하지 않았고, 순찰에서 돌아온 21시 40분, 보관소는 비어 있었다. 근무일지의 그 줄은 정호 스스로 긁어 지웠다.
보관소 문 열쇠는 그 뒤로 한 번도 돌리지 못했다. 정호는 그 열쇠를 녹하역 승강장에 두고 떠났다.

> 그 여성이 누구였는지는 **게임 안에서 끝까지 확정하지 않는다.** (하연의 어머니였을 가능성 / 낯선 사람 / 하준의 기억이 만든 형상 — 엔딩마다 해석이 다르게 읽히도록 단서만 둔다)

## 2. 맵 구성 — 두 개의 녹하역

각 맵은 **[과거 2016]** 과 **[현재 폐역]** 두 버전이 있다. 역 곳곳의 **'정지된 시계'** 를 조사하면 시간대가 전환된다.

```
               [3-5 관제실 / CCTV실] (잠김)
                        │
[3-4 승강장] ── [3-3 개찰구] ── [3-2 역무실]
                        │
                 [3-1 대합실]
                        │
             [3-6 유실물 보관소(과거)]
```

| ID | 맵 | 과거 (2016.11.04 19:00~22:00) | 현재 (폐역) |
|---|---|---|---|
| 3-1 | 대합실 | 퇴근 인파의 그림자들, 매점 불빛, 실종 전단 없음 | 셔터 내려진 매점, 벽 가득 **바랜 실종 전단(윤하준)** |
| 3-2 | 역무실 | 정호의 책상, 근무일지(현재 페이지), 무전기 소리 | 먼지, 서랍 속 **긁어 지운 근무일지 원본** |
| 3-3 | 개찰구 | 정상 작동. 교통카드 찍는 소리 | 차단봉이 전부 내려진 채 녹슨 |
| 3-4 | 승강장 | **벤치에 노란 우비의 아이**(조사 불가, 다가가면 사라짐) | 벤치에 정호의 **역무원 모자** |
| 3-5 | 관제실 | 잠김 (정호만 출입) | 잠김. 문 앞에 녹슨 자물쇠 |
| 3-6 | 유실물 보관소 (과거) | 난로, 아이용 컵에 담긴 우유, 하연이 1장 시작 때 본 **같은 선반** | — (진입 불가: "지금의 보관소"는 허브이므로) |

> 3-6은 허브와 **같은 방의 10년 전 모습**이다. 선반 위치, 카운터, 스피커가 동일. 플레이어가 "여기가 거기였구나"를 알아차리는 공간.

```

  → [3-1 현재] 폐역 대합실 진입. 실종 전단(윤하준) → 하연 동요
  → [3-2 현재] 근무일지 원본 (21:20 줄 긁힘) / 역무실 시계로 첫 시간 전환
  → [3-2 과거] 정호의 그림자 · 무전 · 당일 근무일지
  → [3-4 과거] 승강장의 노란 우비 (다가가면 사라짐)
  → [3-6 과거] 보관소: 난로 · 우유 · 아이 모자 → 정호의 기억 대사
  → 과거/현재 비교 퍼즐 3개 → 관제실 열쇠 조각 3개
  → [3-5] 관제실: CCTV 재생 퍼즐 → **반전**
  → [3-4 현재] 승강장에서 정호와 대면, 열쇠 반환
```

## 4. 퍼즐 상세 — 과거/현재 비교

### 퍼즐 ① 매점의 시계 (3-1)
- 과거 매점 벽시계: 19:30에서 멈춤. 현재 매점 셔터에 시계 자국만.
- 과거 매점 주인 그림자에게 말을 걸면: "꼬마 하나가 승강장에 혼자 있던데, 누나는 아까 나가더라고." *(누나 = 하연 — 첫 직접 증언)*
- 현재 셔터 아래 틈을 조사 → 매점 장부 → 「18:50 바나나우유 1개 — 여자아이(7살쯤) 계산, 남자아이 거 사 줌」
- 보상: **열쇠 조각 1**

### 퍼즐 ② 개찰구 기록 (3-3)
- 과거 개찰구 화면에 '마지막 통과 기록' 5건이 흐른다.

| 시각 | 방향 | 카드 |
|---|---|---|
| 18:40 | 입장 | 어린이 |
| 18:40 | 입장 | 어린이 |
| 18:52 | **퇴장** | 어린이 |
| 21:22 | 입장 | 일반 |
| 21:31 | 퇴장 | 일반 + (동반 어린이 무임) |

- 현재 개찰구 녹슨 차단봉 중 **3번 게이트**만 조사 가능 → "들어간 아이는 둘, 나간 아이는 하나" 문장을 맞추는 선택지.
- 정답 선택: **18:52 퇴장 / 21:31 동반 퇴장** 두 줄을 고른다.
- 보상: **열쇠 조각 2**
- 하연 독백: "18시 52분에… 나간 어린이가 하나."

### 퍼즐 ③ 근무일지 복원 (3-2)
- 과거 근무일지(정호가 쓰는 중)와 현재 원본(긁혀 지워진)을 **겹쳐 보기**.
- 과거에선 21:20 줄이 아직 비어 있다. 현재에선 긁혀 있다.
- 과거의 정호 그림자에게 '현재의 연필'(역무실 서랍)을 건네면, 그림자가 21:20 줄을 쓰다 멈춘다:
  > *21:20 여성 1명, 윤하준 보호자라며 인계 요청. 신분 확인 — (여기서 끊김)*
- 일지 상단: **날씨: 맑음** ← 2장 일기 「그날은 비가 왔다」의 반증
- 보상: **열쇠 조각 3**

### 퍼즐 ④ CCTV 재생 (3-5 관제실)
- 조각 3개로 관제실 자물쇠를 연다. 모니터 4대, 테이프 6개.
- 테이프 라벨의 시각을 보고 **시간 순서대로** 재생해야 영상이 이어진다. 순서가 틀리면 영상에 노이즈와 함께 **현재의 하연이 화면 속에서 카메라를 보고 있는** 장면이 끼어든다 (정신력 -1).

| 테이프 | 화면 | 내용 |
|---|---|---|
| 18:40 | 개찰구 | **노란 우비의 남자아이 손을 잡은 빨간 가방의 여자아이** 입장 |
| 18:45 | 승강장 | 여자아이가 남자아이를 벤치에 앉히고 무언가 말한다 |
| 18:52 | 개찰구 | 여자아이 **혼자** 퇴장. 뒤돌아보지 않는다 |
| 19:30 | 승강장 | 역무원이 아이에게 모자를 씌워 준다 |
| 21:22 | 개찰구 | 우산을 든 여성 입장 (얼굴은 노이즈) |
| 21:31 | 개찰구 | 여성과 **모자를 쓴 아이** 퇴장 — 아이의 우비 색은 흑백 화면이라 알 수 없다 |

- 18:45 화면을 확대(조사)하면 여자아이의 빨간 가방에 달린 이름표: **「윤하연」**

## 8. 시간대 전환 연출

- 전환 시: 0.4초 화이트 노이즈 + 화면이 VHS처럼 흔들림. 과거는 **따뜻한 회갈색 톤 + 미세 필름 그레인**, 현재는 기본 녹청 톤.
- 과거의 사람들은 전부 1장 그림자 동료와 같은 실루엣. 단, **노란 우비의 아이만 색이 있다.**
- 현재 시간대에서 일정 시간(90초) 이상 있으면, 안내방송이 저절로 나온다:
  > *「…윤하준 어린이 보호자를 찾습니다. …윤하연 승객님, 윤하연 승객님.」*

## 9. 사운드

| 구간 | 베이스 환경음 | 주변음 (랜덤) |
|---|---|---|
| 과거 역 | 군중 웅성임(알아들을 수 없음), 열차 진입/출발, 개찰구 '삑' | 아이 웃음, 무전기 잡음, 매점 비닐 소리, 하이힐 발소리 |
| 현재 역 | 바람, 형광등 하나의 지직거림 | 셔터 흔들리는 소리, 쥐, 먼 데서 열차가 지나가는 진동(운행하지 않는데도) |
| 과거 보관소 | 난로 타닥임, 시계 초침 | 컵 내려놓는 소리, 아이가 다리를 흔드는 소리 |
| 관제실 | 모니터 고주파음, 테이프 감기는 소리 | — |

**BGM은 3곳만**: CCTV 반전 직후(아주 낮은 현악 지속음, 짧게) / 승강장 클라이맥스(하모니카 단선율) / 반환 장면(보관소 오르골, 1장과 같은 악기)
