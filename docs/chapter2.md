## 1. 개요

| 항목 | 내용 |
|---|---|
| 유실물 | 물에 젖어 부푼 그림책 「비 오는 날의 늑대」. 꼬리표: 분실일 2016.11.04 |
| 기억의 주인 | **한은솔** (당시 9세) — 녹하역 근처 아동병원 장기 입원 환자 |
| 기억 공간 | 비가 새는 아동 병동 '해바라기 병동'. 복도 끝이 계속 길어지고, 그림책 장면이 병동 안에 실체화된다 |
| 핵심 퍼즐 | 찢어진 페이지 6장을 모아, 그림책의 **'진짜 결말'** 순서로 붙인다 |
| 공포 포인트 | 늑대(첫 추격) · 물이 차오르는 복도 · 그림 속 인물이 움직이는 벽화 |
| 본편 연결 | 그림책 뒤표지 낙서 "누나가 기다리라고 했어" → **하준이 2016.11.04 승강장에 혼자 있었다**는 첫 증거 |

### 한은솔의 사연
2016년 11월 4일 금요일 저녁. 외출 허가를 받아 엄마와 녹하역에 있던 은솔은 승강장 벤치에서 울고 있는 **노란 우비의 남자아이**를 봤다. 아이는 "누나가 금방 온다고 했어"라는 말만 반복했다. 은솔은 아이 곁에 있어 주고 싶었지만, 엄마는 병원 복귀 시간에 늦었다며 은솔의 손을 끌었다. 은솔은 아이가 외롭지 않게 자기가 제일 아끼던 그림책을 두고 갔다.
은솔은 그 뒤로 퇴원하지 못한 날들이 길었다. 병동 침대에서 그 아이를 계속 생각했다. "그 애, 누나 만났을까."

> 은솔은 살아 있다. 지금은 19세. 기억 공간은 '그날 이후 병동에 갇혀 있던 은솔의 마음'이다. (1장의 도윤도 생존 인물 — 이 게임의 '주인'은 유령이 아니라 **후회에 머무른 사람들의 기억**이다.)

## 3. 진행 흐름

```
보관소에서 그림책 조사
  → [2-3] 간호사실 진입. 면회 기록부 → 은솔 = 3호실
  → [2-2] 은솔 침대 → 표지만 남은 그림책 (페이지 0/6)
  → [2-1][2-4][2-2] 페이지 4장 수집 (복도 벽화 · 놀이방 인형극 · 병실 베개 밑 · 링거대)
  → [2-3] 호출벨 퍼즐 → 처치실 열쇠
  → [2-5] 처치실 → 5번째 페이지
  → [2-4] 인형극 무대에서 페이지 붙이기 (중간 점검: 5장)
  → 6번째 페이지는 '그림 속'에 있다 → 늑대 추격 구간 → [2-6] 옥상
  → 최종 배열 → 은솔 등장, 그림책 반환
```

## 4. 퍼즐 상세

### 퍼즐 ① 면회 기록부 & 호출벨
- **간호사실 호출벨 패널**: 병실 1~6호 버튼. 3호실 불만 계속 깜빡인다.
- **면회 기록부**(2016.11.04 페이지): 「3호 한은솔 — 외출 15:00 / 복귀 예정 19:00 / 실제 복귀 19:40 (보호자: 지하철 지연)」
- 패널 아래 메모: *"밤에 무서우면 벨을 눌러. 짧게, 길게, 짧게 — 그럼 언니가 올게. — 간호사 수진"*
- **정답**: 3호실 버튼을 **짧게 → 길게 → 짧게** (짧게 = 조사 1회, 길게 = 조사 버튼 홀드 1초 / 모바일은 길게 누르기)
- 성공 시: 간호사실 서랍이 열리며 **처치실 열쇠**.
- 오답 시: 모든 호출벨이 동시에 울리고 복도 끝 불이 하나 꺼진다(정신력 -1, 반복 시 -1씩, 최대 3회).

### 퍼즐 ② 페이지 수집 (6장)
| 페이지 | 위치 | 획득 방법 |
|---|---|---|
| p1 | 2-2 은솔 베개 밑 | 조사 |
| p2 | 2-1 복도 벽화 '토끼' | 벽화를 조사하면 토끼 그림이 한 칸 옆으로 움직여 있다. 3번 조사하면 그림이 벽에서 떨어지며 페이지 |
| p3 | 2-4 인형극 무대 | 인형 3개(아이 · 토끼 · 늑대)를 올바른 위치에 세우면 막이 열림 |
| p4 | 2-1 링거대 | 링거 팩 속에 페이지가 접혀 들어가 있다 |
| p5 | 2-5 처치실 | 처치대 아래. 들어가면 문이 닫히고 10초간 암전 (연출만) |
| p6 | 벽화 속 '늑대의 굴' | 추격 구간 종료 후 2-6 옥상 화단에서 획득 |

### 퍼즐 ③ 진짜 결말 배열
그림책 「비 오는 날의 늑대」 — 페이지에는 그림과 한 문장씩.

| 페이지 | 그림 | 문장 |
|---|---|---|
| A | 비 오는 정류장, 혼자 앉은 아이 | 비가 오는 날, 아이는 혼자 기다렸어요. |
| B | 늑대가 우산을 들고 다가온다 | 늑대가 말했어요. "따뜻한 데로 데려다줄까?" |
| C | 아이가 고개를 젓는다 | "아니야. 누나가 여기서 기다리랬어." |
| D | 늑대가 아이 옆에 우산을 씌우고 앉는다 | 늑대는 아무 말 없이 우산을 씌워 주었어요. |
| E | 멀리서 달려오는 누군가의 실루엣 | 빗속에서 누군가 아이의 이름을 불렀어요. |
| F | 아이와 누군가가 손을 잡고 걷는 뒷모습 | 아이는 기다린 보람이 있었답니다. |

- **함정 결말**: B 다음에 F를 놓으면 "아이는 늑대를 따라갔어요"로 문장이 **스스로 바뀐다**. 이 배열로 확정하면 늑대가 병동을 배회하기 시작한다(추격 강화).
- **정답**: A → B → C → D → E → F
- 단서: 놀이방 칠판에 은솔이 적은 글 *"늑대는 나쁜 애가 아니야. 우산을 씌워 줬잖아."*

## 5. 위협 요소 — 늑대 (첫 추격)

| 항목 | 내용 |
|---|---|
| 정체 | 그림책의 늑대가 벽화에서 빠져나온 것. 은솔에게 '아이를 데려가는 어른'에 대한 공포가 섞인 형상 |
| 외형 | 3타일 높이의 검은 형체, 우산을 쥔 긴 팔. 젖은 털에서 물이 뚝뚝 |
| 등장 조건 | p5 획득 후 복도 진입 시 1회 고정 / 함정 결말 확정 시 이후 상시 배회 |
| 행동 | 벽화 → 복도로 걸어 나옴. 하연과 같은 속도. **물웅덩이를 밟으면 소리로 위치가 들킨다** |
| 회피 | 병실 침대 밑, 놀이방 인형극 무대 뒤에 숨기 가능 (숨으면 BGM이 즉시 줄고 발소리만) |
| 잡히면 | 화면이 그림책 페이지처럼 넘어가며 해당 방 입구로 복귀. 정신력 -1 |
| 종료 | 옥상 문(2-6)에 도달하면 늑대가 문 앞에서 멈추고, 우산을 바닥에 두고 사라진다 |

> 늑대는 마지막에 '해치지 않는 존재'였음이 드러난다. 은솔이 그날 본 '아이 곁에 남아 준 누군가'의 상징 (3장 역무원과 연결).

## 6. 주요 이벤트 & 대사

### E2-01. 진입 (간호사실)
*(빗소리. 형광등 대신 아이용 야간등이 은은하게 켜져 있다.)*
**하연**: …병원. 이번엔 병원이야.
*(호출벨 패널의 3호실 불이 깜빡인다.)*

### E2-02. 은솔의 침대 (2-2)
*(이불이 흠뻑 젖어 있다. 베개 위에 표지만 남은 그림책.)*
**하연**: 「비 오는 날의 늑대」… 속이 다 뜯겨 나갔어.
*(뒤표지를 조사하면)*
> *(크레파스로 삐뚤빼뚤)* 누나가 기다리라고 햇어

**하연**: ……
**하연**: 'ㅆ' 받침을 이렇게 틀리는 애를… 알아.
*(일기 자동 기록 — 아래 7장. 이 문장은 **거짓**으로 적힌다.)*

### E2-03. 늑대 첫 등장 (p5 획득 후 복도)
*(복도 벽화의 늑대 그림이 비어 있다.)*
*(복도 끝에서 물웅덩이를 밟는 소리. 철벅. 철벅.)*
**하연**: …그림에서, 나왔어.
*(BGM: 추격 — 낮은 첼로 반복 + 빗소리 증폭)*

### E2-04. 옥상 (2-6) — 클라이맥스
*(비가 그쳐 간다. 난간 너머로 녹하역 승강장이 내려다보인다.)*
*(화단에서 마지막 페이지 F. 배열 완성 후 그림책을 펼치면, 젖은 종이가 마른다.)*
*(난간 앞에 환자복 차림의 소녀 실루엣.)*

**은솔**: 그 애… 누나 만났어?
**하연**: ……
**은솔**: 엄마가 손을 잡아끌어서, 이 책밖에 못 주고 왔어. 계속 생각났어. 내가 옆에 있어 줬으면 달라졌을까.
**은솔**: 그 애가 그랬어. 누나는 거짓말 안 한다고. 금방 온다고 했으니까 금방 올 거라고.
*(하연이 그림책을 건넨다.)*
**은솔**: …결말, 고쳐 줬네. 누군가 이름을 불러 주는 걸로.
**은솔**: 언니. 그 애 이름 알아?
- 선택지
  - **[하준이야.]** → 은솔: "하준이. …예쁜 이름이다. 이번엔 꼭 불러 줘." *(플래그 `ch2_said_name`)*
  - **[……모르겠어.]** → 은솔: "그래…" *(정신력 -1)*

*(은솔이 사라지고, 난간 아래 승강장에 노란 우비가 잠깐 보였다 사라진다.)*

### E2-05. 보관소 귀환
**보관소 직원**: 그 책, 꽤 오래 젖어 있었어요.
**보관소 직원**: …그 아이는 그날 비를 맞지 않았어요. 누군가 우산을 씌워 줬거든요.
**하연**: 어떻게 알아요?
**보관소 직원**: *(대답 없음. 직원의 소매 끝이 젖어 있다.)*

## 9. 사운드 (오디오 원칙 준수)

| 맵 | 베이스 환경음 | 주변음 (랜덤) |
|---|---|---|
| 복도 | 빗소리(천장 누수), 물방울 | 링거대 바퀴 구르는 소리, 아이 기침, 멀리서 호출벨 한 번, 슬리퍼 끄는 소리 |
| 병실 | 창문 빗소리, 가습기 | 이불 스치는 소리, 아이 숨소리, 오르골 한두 음 |
| 간호사실 | 형광등, 냉장고 | 전화 수화기 내려놓는 소리, 차트 넘기는 소리 |
| 놀이방 | 거의 무음 + 비 | 블록 무너지는 소리, 인형 눈 굴러가는 소리, 아이 웃음 끝자락 |
| 처치실 | 무음 | 금속 트레이 부딪힘, 고무장갑 소리 |
| 옥상 | 잦아드는 비, 바람 | 멀리 열차 진입음 |

**BGM은 3곳만**: 늑대 추격(첼로 반복) / 옥상 클라이맥스(피아노 + 빗소리 감소) / 반환 장면(그림책 오르골 「기다림」)
