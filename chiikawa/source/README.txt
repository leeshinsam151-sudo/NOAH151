전주치이카와 2.06

실행
1. 기존 전주치이카와는 작업표시줄 아이콘 우클릭 → 종료합니다.
2. 새 EXE를 기존 EXE와 같은 폴더에 놓고 실행하면 기존 설정과 친구 기록을 이어 씁니다.
3. 설치 없이 EXE 한 개로 실행합니다. 기존 버전과 같은 Windows/.NET Framework 환경을 사용합니다.

이번 버전
- 하트는 친밀도 표시와 꽃다발 받아줘 ♥ 문구에 남겼습니다. 간식·완료 알림·설정 문구와 꽃다발 주변의 하트 장식은 제거했습니다.
- 간식을 기다리는 시간 제한을 없앴습니다. 한 번에 포만감 +25, 최대 100이며 배가 꽉 찼을 때만 거절합니다.
- 간식은 친밀도 +5, 함께한 실행 시간은 1분마다 친밀도 +1입니다. 친밀도는 계속 누적됩니다.
- 친밀도 숫자는 기본으로 숨깁니다. 친구 우클릭 메뉴에서 확인할 수 있고, 움직임 설정 → 친구 옆에 친밀도 숫자 표시를 켜면 하트와 숫자가 표시됩니다. 처음 이 버전으로 바꾸면 기존 기본 표시 설정도 숨김으로 시작합니다.
- 친밀도 100, 200, 300…을 처음 달성하면 꽃다발 세 송이를 보여줍니다.
- 친구 기록 → 간식 없이 배고파지기까지는 0~360분으로 설정할 수 있습니다. 이전 간식 간격은 더 이상 이 값을 제한하지 않습니다.
- 0분은 포만감과 관계없이 항상 우는 표정입니다. 간식 먹기와 꽃다발 같은 특별 동작은 잠시 우선 표시합니다.
- 1분부터는 설정한 실행 시간이 지나 포만감이 20 이하가 되면 계속 울고, 간식을 먹으면 다시 평소 표정이 됩니다.
- 기본 배고픔 시간은 60분입니다. 컴퓨터 잠금·절전 시간은 함께한 시간과 포만감에서 제외합니다.
- 기본 앉아 쉬기는 20~30초입니다. 움직임 설정 → 앉아있는 시간 줄이기를 켜면 기존 6~11초(얌전 모드 4초)로 돌아갑니다.
- 어질어질은 머리 위에서 마우스를 같은 방향으로 한 바퀴 그리면 나옵니다(6초 이내). 화면 밖으로 원을 그릴 필요가 없습니다.
- 원을 그리는 동안 슬라이딩보다 어질어질을 우선합니다. 이미 슬라이딩 중이어도 원을 그릴 수 있습니다.
- 몰래 하는 군무는 친구 둘 이상이 같은 바닥에 있을 때 커서를 친구들에게서 떨어뜨린 상태로 4초 지나면 시작합니다.
- 다른 곳에서 커서를 움직여도 군무가 시작됩니다. 서로 몸이 겹칠 필요가 없습니다. 얌전 모드에서는 자동 군무가 나오지 않습니다.
- 우클릭 → 동작 바로 보기에서 어질어질과 몰래 하는 군무를 직접 볼 수 있습니다. 군무는 바닥의 친구 둘 이상이 필요합니다.
- 비밀 조종사는 같은 친구를 10초 안에 세 번 휙 던지면 나옵니다. 세 번째도 먼저 던진 방향으로 튕겨 날아갑니다. 이어서 헬리콥터와 고글 모습으로 천장까지 올라간 다음 천장에 붙어 기어 다닙니다.
- 첫 번째와 두 번째에는 고글이 나오지 않습니다. 살짝 놓거나 10초가 지나면 던지기 횟수를 초기화합니다. 상승 중 다시 잡거나 천장에 도착하면 고글을 종료합니다. 천장 도착 후에는 천장·벽·얌전 모드 설정을 따릅니다.

- 평소 클릭 반응은 눌리기와 폴짝 뛰기입니다. 우는 모습은 배고플 때만 나오며, 0분의 항상 우는 표정은 선택 시 계속 적용됩니다.
- 가장자리 빛의 기본 폭을 화면 짧은 변의 12%로 넓혔습니다(FHD 약 130px). 선명한 가장자리와 부드러운 안쪽 번짐이 함께 숨쉬듯 밝아집니다.
- 알림 설정에서 피치·핑크·보라·하늘 / 노을 / 오로라 / 무지개를 선택합니다. 빛의 폭과 진하기도 각각 세 단계로 조절할 수 있습니다. 정각창 미리보기로 저장 전에도 확인합니다.

기존 기능
- 함께한 시간, 친밀도, 메모, 할 일, 타이머, 발견한 비밀은 재실행해도 이어집니다. 함께한 시간은 여러 마리여도 중복 계산하지 않습니다.
- 친구들이 만나면 살짝 튕기고 반대 방향으로 걷습니다. 쉬기·슬라이딩·드래그 중에도 몸이 겹치지 않도록 분리합니다.
- 슬라이딩 반응 대기는 기본 0.12초이며 움직임 설정에서 조절할 수 있습니다.
- 정각 알림 카드와 화면 가장자리 빛은 확인 버튼이나 ×로 직접 닫을 때 함께 종료됩니다.
- 알림 설정에서 자동 시작, 평일 정각 알림 제외, 빛 효과를 설정할 수 있습니다.

기록
Windows 계정의 AppData/Roaming/걸어다니는친구/전주치이카와_할일.xml에 친구 기록을 저장합니다.
2.03·2.04·2.05의 기존 친밀도·함께한 시간·메모·할 일·발견한 비밀을 가져옵니다.
저장 시 이전 정상 기록의 .bak 파일을 유지합니다. 기록을 유지하려면 이 파일들을 지우지 마세요.
