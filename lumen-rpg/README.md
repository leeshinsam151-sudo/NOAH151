# 꺼진 등불의 땅

빛이 사라진 세계에서 꺼진 봉화를 다시 밝히는 탑뷰 도트 액션 RPG. 전체 6장과 엔딩 3종.

## 실행
`index.html`은 Claude 아티팩트용 본문 조각이라, 브라우저에서 바로 열어도 동작해요. 같은 폴더의 `ch4.js`, `ch5.js`, `ch6.js`, `extras.js`, `art.js`, `audio.js`를 함께 둬야 해요.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 엔진(렌더링, 빛, 충돌, 입력, 소리)과 1~3장 |
| `ch4.js` | 4장 잿빛 사막, 모래 고래 바하르 |
| `ch5.js` | 5장 작은 세계, 위장 몬스터, 찍찍왕 |
| `ch6.js` | 6장 별등탑, 거인 맞대결, 엔딩과 에필로그, 장별 막간 장면 |
| `extras.js` | 캐릭터 화면, 가방 화면, 장신구, 부탁, 모아 베기, 등불 기술, 창 |
| `art.js` | 큰 그림: 대화 초상화, 보스 등장, 시작·장 제목 화면, 막간·에필로그 그림 |
| `audio.js` | 소리 보강: 잡음 기반 소리 엔진, 보스 포효, 상황별 효과음, 특수 지역 발소리, 지역 환경음 |

## 조작
방향키 이동 · A 공격(길게 눌러 모아 베기) · S 구르기 · D 등불 섬광 · Z/X/C 등불 기술 · E 대화 · Q 회복약 · R 무기 바꾸기 · K 캐릭터 · I 가방 · F 대장간 · M 지도 · Esc 메뉴
